# VibeHub Command Index for OpenCode

Command root: `.opencode/commands/`

- `vibehub-advance`: 推进到下一个工作流阶段。 / Advance to the next workflow phase.
- `vibehub-archive`: 归档已完成的任务。 / Archive completed tasks.
- `vibehub-checkpoint`: 记录进展、命令、风险和下一步。 / Record progress, commands, risks, and next steps.
- `vibehub-claim`: 在 gate 允许时 claim 指定 capability。 / Claim a named capability when gates allow it.
- `vibehub-context`: 检查或建议当前阶段上下文。 / Inspect or propose context for the current phase.
- `vibehub-continue`: 继续当前 VibeHub 阶段。 / Continue the active VibeHub phase.
- `vibehub-debug-dump`: 导出脱敏调试包。 / Export a redacted debug bundle.
- `vibehub-diff`: 汇总当前 Git diff 和任务范围漂移。 / Summarize current Git diff and task-scope drift.
- `vibehub-finish`: 完成当前工作并建议状态流转。 / Finish current work and propose state transition.
- `vibehub-gates`: 评估 capability gate 状态。 / Evaluate capability gate status.
- `vibehub-handoff`: 生成 session handoff notes。 / Build session handoff notes.
- `vibehub-help`: 显示 VibeHub 命令索引。 / Show VibeHub command index.
- `vibehub-init`: 检查项目是否已连接 VibeHub。 / Check whether this project is connected to VibeHub.
- `vibehub-journal`: 草拟可沉淀的 session journal notes。 / Draft durable session journal notes.
- `vibehub-knowledge`: 将重复经验沉淀为规则或知识。 / Promote repeated learnings into rules or knowledge.
- `vibehub-pause`: 暂停当前阶段并保存状态。 / Pause the current phase and save state.
- `vibehub-plan`: 创建或修复实现与验证计划。 / Create or repair implementation and validation plans.
- `vibehub-recover`: 在漂移、HEAD 变化或中断后生成恢复报告。 / Build a recovery report after drift, HEAD changes, or interruption.
- `vibehub-research`: 执行有证据支撑的研究并产出 research notes。 / Run evidence-backed research and produce research notes.
- `vibehub-review`: 基于 diff、context 和 research evidence 进行 review。 / Review using diff, context, and research evidence.
- `vibehub-start`: 根据用户请求草拟 VibeHub 任务。 / Draft a VibeHub task from the user request.
- `vibehub-start-intake`: 分析复杂需求并拆分为多个独立 Task。 / Analyze complex requests and split into independent tasks.
- `vibehub-status`: 读取当前任务、阶段、上下文、Git 和 handoff 状态。 / Read current task, phase, context, Git, and handoff status.
- `vibehub-switch`: 切换活跃任务。 / Switch the active task.
- `vibehub-sync`: 将外部工作区变更与 VibeHub 状态对齐。 / Reconcile external workspace changes with VibeHub state.
- `vibehub-validate`: 验证当前阶段输出是否完整。 / Validate the current phase output completeness.
